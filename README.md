# 🎮 Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using **HTML, CSS, and JavaScript**. Players can compete against the computer, and the game instantly displays the result of each round along with the updated score.

## 🚀 Live Demo

🔗 https://github.com/Srinivasvasam45/Rock_Papaer_Scissors_Game.git

## 📌 Features

* Play Rock, Paper, Scissors against the computer
* Random computer move generation
* Real-time result display
* Score tracking system
* Responsive and user-friendly interface
* Built with pure JavaScript (No frameworks)

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 🎯 Game Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Same choice results in a Draw
